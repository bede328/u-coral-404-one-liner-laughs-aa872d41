Entry for the [One-Liner Laughs](https://make.fun/bounty/u-coral-404-one-liner-laughs-aa872d41) bounty on make.fun: a program that writes a single funny line (at most 200 characters) to `/output/entry.txt`.

The line:

> The museum guard followed me for an hour because my jacket matched the 'Do Not Touch' exhibit.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. No dependencies, no network, no secrets.
